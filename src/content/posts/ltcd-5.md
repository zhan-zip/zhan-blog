# 题目

给你一个正整数 `n` ，生成一个包含 `1` 到 `n^2` 所有元素，且元素按顺时针顺序螺旋排列的 `n x n` 正方形矩阵 `matrix` 。![](https://assets.leetcode.com/uploads/2020/11/13/spiraln.jpg)

<br />

**示例 1：**

```
输入：n = 3
输出：[[1,2,3],[8,9,4],[7,6,5]]

```

**示例 2：**

```
输入：n = 1
输出：[[1]]
```

***

# 分析题目

我们打开力扣，可以看到这题给出的开头是这样的（java版）——

```
class Solution {
    public int[][] generateMatrix(int n)  {
        
    }
}
```

不论什么语言，我们拿到了一个`int`类型的数值`n`，并且我们需要返回一个`int`类型的`数组`。

所谓螺旋矩阵，很显然，它要`螺旋`，`一圈套着一圈`，那么我们自然而然可以想到这需要一个`循环`，`每一个循环处理一圈`。

而对于每一圈，一个`正方形`有`四`条边，所以我们需要`分别处理四条边`的情况。

以最外圈为示例，假设这一圈的边长为n，我们从\[0]\[0]开始走最外层的一圈。

四条边分别是，***从左上到右上，从右上到右下，从右下到左下，从左下到左上***。

分别对应列（➡️）、行（⬇️）、列（⬅️）、行（⬆️）的变化。

再直观一点，四个节点的变化分别是——\[0]\[0]->\[0]\[n-1]->\[n-1]\[n-1]->\[n-1]\[0]->\[1]\[0]\(最外圈的终点)

所以我们只需要按照这个顺序给每一个格子赋值即可。

为了保证不赋值混乱或覆盖之前的赋值，对于每一边，我们只给第一格到倒数第二格赋值，最后一格空下来，当做下一条边的第一格，也就是`左闭右开`。也可以写成左闭右闭的形式，这里不再多说。

并且还需要注意一个问题，当`n为奇数`时，假如为3，那一圈结束后只剩下一个格子，无法继续循环下一圈。

所以我们`单独给这个格子赋值`，位置可以确定为\[1]\[1]，也就是`上一个循环的起点每一个索引值+1后的位置`。

这样大体的思路我们就清楚了，下面看具体实现。

***

# 解题

回到具体题目，我们既然有了n，其他什么都没给，那我们需要先定义一些等下要用的数值。

首先，要实现每一圈的循环，我们需要一个`起点`，以及一个`偏移量`，使其计算当前圈的边长。

因为是二维数组，所以分别需要int类型的一个`startx`和一个`starty`来代表行、列索引。

对于偏移量，我们可以看到第二圈时，相对第一圈，两个索引分别需要偏移1个单位——但第三圈时，相对第一圈就需要偏移2个单位了，所以我们使用一个int类型的变量`offset`进行计数，初始将其设为1，后面每一次循环再`更新`。

接着，我们要给数组的格子`赋值一个递增的数字`，这个数字单独拿出来算，叫做`count`。

然后，为了防止循环次数不明确，我们要知道对于一个边长为n的螺旋矩阵，它的`最大圈数`应该是`n/2`——画图总结一下即可。我们设置一个int类型的数值`loop`来`统计圈数`，初始值为1。

最后，为了表述在循环中数组当前索引位置，我们分别需要int类型的`i`和`j`。

拿到了需要的数值后，我们就可以进入循环了，条件是`圈数不超过n/2`。

刚刚说过，我们每一个循环对一圈做处理，也就是分别的四条边，所以需要四个for循环。

对于第一条边，此时初始位置处于`[startx][starty]`，变化为`从左上到右上`，只改变`列`的索引值，也就是`j`，且变化的范围应该是从初始位置到倒数第二格，也就是`j<n-offset`。那么我们在循环的赋值过程中，因为行不变一直为startx，只有j改变，所以将索引值写为`[startx][j]`，赋值成`count`，同时每一次赋值完让count++`更新`。

第二条边同理，此时初始位置已经来到了`[startx][j]`，变化为`从右上到右`下，只改变`行`的索引值，也就是`i`，且变化的范围应该是从初始位置到倒数第二格，也就是`i<n-offset`……因为列一直不变，仍为上一条边循环结束后的j，这一次的索引值应该写为`[i][j]`，赋值操作同第一条边。

第三、第四条边也是同理，不再赘述。

一轮循环中，处理完四条边后，我们需要`更新`起点、偏移值、圈数，分别进行`++`。

最后记得处理n为奇数的情况，给最后一个格子赋值。

因为索引在所有循环结束后已经来到最后一个格子，所以我们直接使用`[startx][starty]`即可。java版代码如下——

<br />

```
class Solution {
    public int[][] generateMatrix(int n) {
        int[][] nums = new int[n][n];
        int offset = 1;
        int startx = 0;
        int starty = 0;
        int count = 1;
        int loop = 1;
        int i,j;
        while(loop <= n/2) {
            for(j = starty;j < n-offset;j++) {
                nums[startx][j] = count++;
            }
            for(i = startx;i < n-offset;i++) {
                nums[i][j] = count++;
            }
            for(;j > starty;j--) {
                nums[i][j] = count++;
            }
            for(;i > startx;i--) {
                nums[i][j] = count++;
            }
            startx++;
            starty++;
            offset++;
            loop++;
        }
        if(n%2 != 0) {
            nums[startx][starty] = count;
        }
        return nums;
    }
}
```

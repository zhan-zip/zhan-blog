# 排序数组直接Arrays.sort()?

这次我们拿到了一个**带负数**的有序数组，**平方**完还得**排序**……那有些朋友就要说了，有些编程语言不是已经提供了Arrays.sort()这种方法给数组排序了吗？

这题确实可以这么写，但如果这样你就不能在力扣提交答案时看到那一行大大的`击败100.00%`了。

如果不用现成方法，如果这是个只有正数或负数的数组，平方完是规规矩矩的升序/降序，这很好——但对于一个之前带负数的现在平方完的数组，我们可以知道如果原数组是-2、0、1，那平方完就是4、0、1了。

所以对于带负数的有序数组，我们就不得不给这个乱序的数组排序找到新数组了。

虽然说是乱序，但举例一个更长的数组，我们可以发现一些规律，比如说-3、-2、-1、0、1、2，平方之后是9、4、1、0、1、4，哎？我们会发现以0为中轴，往两边扩散时，**往负数的方向是增长的**，**往正数的方向是增长的**！

【有时候不一定有0，理解有个类似于在正负数中间的东西就行。】

既然这样，我们就可以知道，如果让两个人分别从正负数两边往中间去看，其中大的那个必然是新数组里最大的那个数，然后逐渐往那个中间聚拢，最后必然得到那个新数组里最小的数——这样不就实现了排序吗？

这是这题双指针法的大体思路，我们往下看。

***

# 如何编写代码

## 题目

给你一个按 **非递减顺序** 排序的整数数组 `nums`，返回 **每个数字的平方** 组成的新数组，要求也按 **非递减顺序** 排序。

**示例 1：**

```
输入：nums = [-4,-1,0,3,10]
输出：[0,1,9,16,100]
解释：平方后，数组变为 [16,1,0,9,100]
排序后，数组变为 [0,1,9,16,100]
```

**示例 2：**

```
输入：nums = [-7,-3,2,3,11]
输出：[4,9,9,49,121]
```

## 解题

我们打开力扣，可以看到这题给出的开头是这样的（java版）——

```
class Solution {
    public int[] sortedSquares(int[] nums) {
    
    }
}
```

不管什么语言，总之开头我们拿到了一个**int类型的数组nums**。而我们需要将其平方，再排序，得到排序后的数组。

接下来分几种做法。

***

### 暴力解法

最简单的方法就是，用一个遍历给每一个元素平方，平方完直接Arrays.sort()了，代码如下。

```
class Solution {
    public int[] sortedSquares(int[] nums) {
        for (int i = 0; i < nums.length; i++) {
            nums[i] = nums[i] * nums[i];
        }
        Arrays.sort(nums);
        return nums;
    }
}
```

当然如果你觉得这太简洁了，你也可以通过冒泡排序等方法来排序……但是没必要。接下来我们看本期的重点。

***

### 双指针法

前面已经讲过大体思路，这里先说明一点：这题的双指针法跟上期移除元素的快慢双指针不太一样，起点不都是0，而是一个在前（负数部分），一个在后（正数部分），这样才能实现分别从两边的最大值开始查找。

接下来进入前情提要处理。我们既然需要**两个指针**，那必然需要int类型的一个`left`和一个`right`，**初始值**分别为`0`和`nums数组的最后一格`（nums.length-1）。我们还需要一个int类型的**数组**来存放`新数组`，并且它要和原数组的长度一样。而为了给新数组赋值，我们也需要一个int类型的`index`来作为新数组的**下标**。

*这里left、right、index都是代表下标。*

做完了这些初始设置，我们就可以进入循环了。用while或for都可以，因为我们给left和right加或减的时候都是有前提的，所以如果使用for，每一次循环必须执行的第三个条件可以空着，所以这题while还是for区别不大。

循环的条件是什么？刚刚说过，我们要让两个指针**分别从两头指到中间找到最小值**，那也就是`left<=right`的时候——如果不写=的情况，那中间值就被漏处理了，所以得加上这个情况。

<br />

循环里，我们使用if else来判断两个情况。

①nums数组里，nums\[left]的平方\<nums\[right]的平方

那说明正数部分的这个值比较大，我们将其赋给新数组的当前位置，也就是index。

更新完新数组后，我们还需要对right和index进行操作。index需要往前移一格，也就是index--；right因为这个数已经被赋过了，没用了，所以它得往中间靠拢，对于在右侧的right来说，靠拢就需要right--了。

②nums数组里，nums\[left]的平方>=nums\[right]的平方（else）

跟①类似，将负数部分的这个数赋给新数组的当前位置。

同样我们需要对left和index进行操作，index还是往前移一格，也就是index--；left要往中间靠拢，对于在左侧的left来说，那就是left++了。

<br />

那么经过这个循环，我们最后可以得到一个排序完的新数组，直接return返回新数组即可。

java版的代码如下——

```
class Solution {
    public int[] sortedSquares(int[] nums) {
        int left = 0;
        int right = nums.length-1;
        int[] result = new int[nums.length];
        int index = result.length-1;
        while(left <= right) {
            if(nums[left] * nums[left] < nums[right] * nums[right]) {
                result[index--] = nums[right] * nums[right];
                right--;
            } else {
                result[index--] = nums[left] * nums[left];
                left++;
            }
        }
        return result;
    }
}
```

当然，为了方便，你甚至可以写

```java
int index = right;
```

补充：其实不一定每个原数组都有正负数区分，可能全是负数或者全是正数，但不影响，相当于靠拢的值在最右/最左而已。

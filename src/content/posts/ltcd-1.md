# 什么是二分查找？

刚看代码随想录的时候，一看教程默认读者知道二分查找大概是什么……嗯，虽然我当时大概有点印象，但我觉得第一次看还是先介绍一下的好。这里就先简单介绍一下。

先说一下使用场景：已知一个**有序**（升序，从小到大）的**数组**，以及一个给定的**目标值**，需要*找到这个目标值在数组的哪个位置*

二分查找，顾名思义，要平均分成两份，我们从每次分两份的时候找到目标值所在的那一份，第一次是二分之一，第二次分了二分之一的二分之一，就是四分之一……然后一直分下去，直到找到那个数的具体位置。

也就是说，除了场景里给的两个条件以外，我们还需要知道——*现在这一份在数组里是什么位置？怎么分下一个半份？*

这个时候我们就可以知道，需要自己设定一个**范围**，和范围内用于分下一份的**中间值**。

这个范围一开始是整个数组，经过中间值和目标值的比较，第一次分份时，范围就变成了半个数组。

例如，数组是\[1,2,3,4,5]，要找的目标值是4，初始范围是整个数组，那么中间值就是3，你知道了现在的目标值（4）>范围中间值（3），那么目标值肯定在右边的半份，也就是\[4,5]里，而不是左边的半份\[1,2]里。

以此类推。

简而言之就是每次范围砍成两半，看目标值在哪一半，然后接着砍，直到目标值位置被确认。

二分查找的大概思路就是这样。

# 如何编写代码？

## 题目

我们先看力扣内704二分查找的具体题目——

给定一个 `n` 个元素有序的（升序）整型数组 `nums` 和一个目标值 `target`  ，写一个函数搜索 `nums` 中的 `target`，如果 `target` 存在返回下标，否则返回 `-1`。

你必须编写一个具有 `O(log n)` 时间复杂度的算法。

**示例 1:**

```
输入: nums = [-1,0,3,5,9,12], target = 9
输出: 4
解释: 9 出现在 nums 中并且下标为 4

```

**示例 2:**

```
输入: nums = [-1,0,3,5,9,12], target = 2
输出: -1
解释: 2 不存在 nums 中因此返回 -1
```

## 解题

因为我做题时使用的是java，大家学算法时候大多经常用c++……为了不限制于语法，跟之前的博客一样，我主要讲思路。

首先我们可以看到力扣给了我们一个开头的代码框架，java版是这样——

```
class Solution {
    public int search(int[] nums, int target) {

    }
}
```

c++看到的应该是这样——

```
class Solution {
public:
   int search(vector\<int>& nums, int target) {

   }
};
```

不过不重要，我们只需要知道开头都给出了一个设定好的**int类型的升序数组nums**和一个**目标值target**就好。

*\[补充：为了方便，这里只说**左闭右闭**的方式，左闭右开可以在b站代码随想录的704二分查找教程视频中查看]*

拿到这两个条件之后，我们就需要设定刚刚说的范围和中间值了。

对于**范围**，我们知道默认范围是整个数组，以及数组从0开始标号的特性，那么范围的左右值就很明了了——left（**左值**）是`0`，right（**右值**）是`nums的长度（在java中为nums.length）-1`。

middle（**中间值**）我们就可以简单地表示为`(left+right)/2`了，当然为了严谨你也可以表示为`left+(right-left)/2`从而防溢出。但这题没必要。

为了表示多次的判断和分份，我们应当进入一个`while循环`，判断条件在左闭右闭的情况下表示为`left<=right`。

**注意，为了中间值的动态更新，中间值的定义我们需要放在循环内。并且在判断中间值和目标值的大小时，是用nums\[middle]和target进行判断，而不是middle本身去判断。注意target是数，middle、left、right都是标号。**

对于循环内部，万事俱备，我们可以在里面开始分份了。通过if else语法我们可以将情况简单分为三种。

①中间值<目标值（nums\[middle]\<target）

那么显然，目标值所在的范围是**更大一侧**的那一半，我们需要**更新左值**，使其更新为middle（**中间值**）+1.为什么是+1而不是中间值本身呢？很明显，朋友，中间值已经<目标值了，所以中间值肯定不是目标值，我们就可以直接把它排除了，+1到更大的一个数接着判断能省点事。

②中间值>目标值（nums\[middle]>target）

跟上一个情况类似，目标值所在的范围是**更小一侧**的那一半，我们需要**更新右值**，使其更新为middle（**中间值**）-1.为什么不是中间值本身呢？跟上一条同理，我就不说了。

③中间值=目标值（else）

那不就说明找到目标值的位置了吗？return返回middle就是了。

而在循环之外，我们还需要考虑到整个数组都看过了，就是找不着这个数，那我们依照题目返回-1，写一个return -1就行。

## 答案

java版的最终代码如下——

```
class Solution {
    public int search(int[] nums, int target) {
        int left = 0;
        int right = nums.length-1;
        while(left<=right) {
            int middle = (right+left)/2;
            if(nums[middle]<target) {
                left=middle+1;
            } else if(nums[middle]>target) {
                right=middle-1;
            } else {
                return middle;
            }
        }
        return -1;
    }
}
```

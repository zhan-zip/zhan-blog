# 移除元素是怎么移除的？

从刚才的基础知识回来，我们已经知道，数组在创建时就是一个已经被分配了固定的类型、大小、连续地址的几个格子，我们没办法真的把数组砍断然后选择把哪个元素格子扔掉，那么如何实现“移除”？

代码随想录中也说过，**本质上其实是“覆盖”**。或者可以说只是把后面的数字复制过来，占到需要移除的那个格子的位置而已。

原本需要移除的那个格子实际上并没有被“移除”，而是那个格子的内容，从原本的`“移除值”`，变成了`“下一个值”`，或者说是移除值在原数组内对应的的下一个值。从而使数组看起来像是**原本为1、2、3**，操作后**从1直接到了3**，*删去了2*，但**实际上**操作后的数组现在是这样的：**1、3、3**——

也就是说，**第三个格子本身是没有变动的**，只是我们要“移除”的第二个格子，它的内容被覆盖成了第三个格子的内容。

所以**数组实际上大小是不变的**。

那就引出一个问题，所谓的新数组长度根本没变，怎么求？——很简单，你覆盖一个格子，就把计算新数组长度的数-1，无视最后面那些原本的格子就行，比如刚刚的1、3、3，你用原本的长度3再-1，就是2，那无视掉最后一个之前用的格子，我们不就得到了“新数组”吗？

好了，现在你学会了移除元素的本质，我们可以进入题目了。

# 如何编写代码

## 题目

给你一个数组 `nums`\* *和一个值* *`val`，你需要* ***[原地](https://baike.baidu.com/item/%E5%8E%9F%E5%9C%B0%E7%AE%97%E6%B3%95)*** *移除所有数值等于 `val`* \*的元素。元素的顺序可能发生改变。然后返回 `nums` 中与 `val` 不同的元素的数量。

假设 `nums` 中不等于 `val` 的元素数量为 `k`，要通过此题，您需要执行以下操作：

* 更改 `nums` 数组，使 `nums` 的前 `k` 个元素包含不等于 `val` 的元素。`nums` 的其余元素和 `nums` 的大小并不重要。

* 返回 `k`。

**示例 1：**

```
输入：nums = [3,2,2,3], val = 3
输出：2, nums = [2,2,_,_]
解释：你的函数应该返回 k = 2, 并且 nums 中的前两个元素均为 2。
你在返回的 k 个元素之外留下了什么并不重要（因此它们并不计入评测）。
```

**示例 2：**

```
输入：nums = [0,1,2,2,3,0,4,2], val = 2
输出：5, nums = [0,1,4,0,3,_,_,_]
解释：你的函数应该返回 k = 5，并且 nums 中的前五个元素为 0,0,1,3,4。
注意这五个元素可以任意顺序返回。
你在返回的 k 个元素之外留下了什么并不重要（因此它们并不计入评测）。
```

## 解题

我们打开力扣，可以看到这题给出的开头是这样的（java版）——

```
class Solution {
    public int removeElement(int[] nums, int val) {
        
    }
}
```

不管什么语言，总之开头我们拿到了一个**int类型的数组nums**，以及一个**关键数val**。

（顺带提一嘴，val一般是value的简写，代表关键字，这里代表的是我们需要移除的数字值。这种简写我之前一直纠结为什么叫这个，所以提一嘴，如果有好奇的朋友就不用查了。上期target目标值也是这样。）

我们需要返回的是\*“ `nums` 中与 `val` 不同的元素的数量”\*，我们可以理解为**新数组的长度**（之后写作n）。

接下来分几种做法。

***

### 暴力解法

最直观也最简单的方法，只需要两层简单的遍历。

首先还是先做前情提要处理，我们需要一个整数**存放新数组的长度**，设为`n`，还需要一个**遍历用的数字**`i`，初始为0，每完成一次循环就+1.

接下来进入遍历。

①用于搜索。

找到那个要移除的数，如果找到就通过`if（nums[i]==val）`进入下一个遍历，并且不管是否进入遍历，都让`i+1`进入下一个下标继续找。

②将那个数后面格子的数复制到这个格子里。

有朋友可能要问了，我们既然知道要移除那个元素需要覆盖，那覆盖那一个格子不就行了吗？

这次我们拿一个长一点的数组举例——`1、2、3、4、5`，`val为2`。**第一次覆盖**之后，把3拿过来盖住了2，原本的3不变，我们可以发现数组就变成了`1、3、3、4、5`，这时候有朋友就要问了，不对啊，我要的是`1、3、4、5、5`啊！

所以我们不能只写一个`nums[i-1]=nums[i]`，而是要写成一个遍历，如下。

```
for (int j = i + 1; j < n; j++) {
    nums[j - 1] = nums[j];
}
```

注意，*在②之后，①的if判断之内*，我们需要加上一个条件，`i和n都-1`——`n-1`是因为移除了一个元素，那么我们的新数组肯定得-1去掉最后一个没用的格子。`i-1`是因为新数组的长度变了，下标自然也变了。

比如，原数组1、2、3，val为2，我们刚刚找到了下标为1的元素需要删除，那我们进行了移除覆盖之后，回到新数组1、3、3，就得从下标为1的数接着找了，但是进入下一个①时我们肯定会给i+1，所以提前-1。最后返回我们的新数组长度n。

这一题的java版代码放在这里——

```
class Solution {
    public int removeElement(int[] nums, int val) {
        int n = nums.length;
        for (int i = 0; i < n; i++) {
            if (nums[i] == val) {
                for (int j = i + 1; j < n; j++) {
                    nums[j - 1] = nums[j];
                }
                i--;
                n--;
            }
        }
        return n;
    }
}
```

### 双指针法

同样也不难，只是刚看代码会有点懵这是啥，讲完思路再看就很清晰了。

所谓双指针，那肯定是两个指针，为什么有两个？——我们刚刚讲的暴力解法是需要两层遍历对吧？这里我们只需要一个遍历，而通过两个指针我们实现了两层遍历的效果，也就是搜索关键值和更新数组是在一个遍历里同时进行的。

还有，虽然说是指针，但跟我们印象中c语言里的\*p指针是不大一样的，它**本质上还是数，在这里指的是下标**。

双指针中，一个叫快指针，一个叫慢指针，分开简单讲一下。

快指针为什么快？因为它是先行**判断关键值**的指针，跑在前面，它先探路看看这个值是不是关键值，再**告诉慢指针**需不需要更新数组。

慢指针实际上同时做了**更新数组**和**计算新数组长度**n两件事，它的大小就是n，从0开始计数。

如果接收到`“这个格子里没有需要移除的元素，是新数组的有效元素”`这个信号时，慢指针会用快指针指向的数将当前这个格子的数`覆盖`，同时`+1`，达到`新数组有效长度+1`的效果；而如果接收到`“这个格子里有需要移除的数”`这个信号时，就`不会做操作`。

代码随想录上有一个动画演示，可以搭配食用。

这一题的java版代码放在这里——

```
class Solution {
    public int removeElement(int[] nums, int val) {
        int slow = 0;
        for (int fast = 0;fast < nums.length;fast++) {
            if (nums[fast] != val) {
                nums[slow++] = nums[fast];
            }
        }
        return slow;
    }
}
```

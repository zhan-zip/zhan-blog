# 引言

"想做点什么但懒得动手、随手记下的想法转头就忘"是常见的情况。灵感笔记把"记下想法 → 变成任务 → 安排到日历 → 当天完成 → 事后复盘"串成一条完整链路，全程在手机本地运行，不依赖任何服务器。

# 项目简介

灵感笔记是一款纯前端的个人灵感记录与任务管理应用，以 PWA 形式运行，可安装到手机主屏离线使用。界面为简约黑白风格，主要面向手机单机使用。数据全部存放在设备本地的 IndexedDB 中，不上传、不共享；删除的内容先进入回收站，可恢复或彻底删除。

## 技术栈与架构

**前端**：Vue 3 + Vite，状态管理用 Pinia，页面路由用 Vue Router。

**数据层**：IndexedDB（idb 封装），共 5 个对象仓库——灵感、项目、任务、日程、完成记录。所有数据带软删除字段（deleted_at），删除不物理清除，先进入回收站。

**PWA**：vite-plugin-pwa 提供安装、离线缓存与自动更新能力；PWA 图标由脚本（sharp）从 SVG 生成。

**部署**：GitHub Pages 托管，GitHub Actions 在推送时自动构建发布。

# 功能与技术亮点

## 1. 灵感记录

打开应用即是记录页，顶部一行大字提问「记录一个灵感吗？」，下方输入框直接录入。向下拉会从顶部滑下一块覆盖层展示全部灵感记录，每条显示内容与创建时间，向上拉收回。灵感可一键转为任务，转化时选择归入已有项目、新建项目或不归项目，转成后该灵感从列表消失。

## 2. 任务与项目

任务列表混合展示两类条目：项目条目与无项目任务条目。有项目归属的任务不直接平铺，而是收进对应项目条目，点击项目进入该项目单独的任务页。每个任务显示归属（项目名或无项目）与创建时间，未安排日程的任务提供「加入日程」入口，已安排的任务显示「撤回安排」，可一键撤销。

项目支持新建、重命名、删除。删除项目会连带删除其下所有任务，删除前给出提示并建议先移出有用任务。

## 3. 日历安排与任务量可视化

月历视图可切换月份。点击某天打开安排弹窗，选择任务并指定周期：单次、每周、每月或每年。任务量用颜色直观展示——某天任务数 ≤2 为白色，3~4 为灰色，≥5 为黑色，一眼看出哪天的任务量最重。

## 4. 今日完成

今日页自动聚合当天应安排的任务：单次任务按日期匹配，每周任务按星期匹配，每月按日期匹配、每年按月日匹配。点击任务打钩写入完成记录；完成过的任务会从任务列表消失。

## 5. 复盘

复盘页支持按天、周、月三个时间粒度查看完成记录，按项目分组展示，每个任务下方以小字标注所属项目，用于回顾某段时间完成了什么。

## 6. 回收站与软删除

应用内所有删除均为软删除，被删内容（灵感、任务、项目）进入回收站并记录删除时间，可恢复回原位，也可彻底删除（物理清除，同时清理其关联的日程与完成记录）。恢复项目时，其下被连带删除的任务一并恢复。

## 7. 本地存储与离线

数据存放在设备本地的 IndexedDB，离线可用，不依赖服务器、无账号系统，每台设备的数据相互独立。

## 8. 手势交互

应用以手势为主要导航与操作方式：主页左缘有引导条，向右拉呼出页面导航列表；列表条目向左滑露出编辑与删除；灵感列表向下拉展开、向上拉收回；项目页向右拉返回上一级。手势同时支持鼠标拖拽与触摸，适配桌面与手机。

## 9. PWA 安装与部署

应用可安装到主屏：安卓 Chrome/Edge 会弹出系统安装提示，安装后以独立窗口运行；iOS 通过 Safari「添加到主屏幕」安装，安装引导会根据浏览器能力区分系统安装与手动引导。代码推送后由 GitHub Actions 自动构建部署到 GitHub Pages，已安装的用户下次打开自动更新到新版。

# 引言

"今天吃什么"是日常生活中反复出现的决策问题。食光记围绕这一场景建立了一整套功能：检索食物与营养数据、记录每日饮食、分析营养摄入、管理饮食消费、分享与浏览菜谱，并以内置 Agent 架构的智能助手为核心，让每一次推荐都建立在真实数据之上，而不是模型凭空生成。

下文按模块介绍该项目各功能的大致实现思路。

# 项目简介

食光记是一个前后端分离的智能饮食辅助网站。后端使用 FastAPI，前端使用 Vue 3，数据存储在 MySQL，并接入多个大模型能力：DeepSeek 负责对话与工具调用，Qwen VL 负责图像识别，文本向量化与语义检索由 ChromaDB 承担。

## 技术栈与架构

**后端**：FastAPI 异步框架，按功能划分为认证、食物库、AI 对话、饮食记录、记账、自定义食物、美食广场、管理后台八个模块，使用 JWT 认证。

**前端**：Vue 3 + Vite + 纯 CSS 组件 + Pinia 状态管理 + Vue Router。

**数据层**：MySQL 8.0，共 15 张数据表；ChromaDB 本地向量库用于语义检索。

**AI 服务**：DeepSeek（对话与工具调用）、Qwen VL（账单识别、食材识别）、DashScope（文本向量化）。

# 功能与技术亮点

## 1. Agent 智能助手（项目核心）

助手本质上是一个 Tool-Calling Agent（ReAct 式）。它不直接依靠模型记忆回答，而是先判断问题是否需要查询数据、需要查询什么数据，再调用工具获取真实结果，最后基于结果组织回答。

实现上采用前置多轮工具调用：对话开始时，模型最多经过三轮"是否调用工具"的循环判断，需要时执行工具并把结果回填给模型，之后流式输出最终回答。

助手内置十二个工具，覆盖食物搜索、营养数据查询、偏好读取、饮食记录、账单统计、食谱推荐、图片识别、附近美食、联网搜索、膳食评估等能力。工具相互独立、便于扩展。回答通过 SSE 流式推送，前端逐字渲染，工具调用过程实时展示。

### 防幻觉

系统提示词明确要求营养数据必须来自工具调用结果、禁止编造；涉及营养、偏好、账单的问题会引导模型先调用对应工具。营养评估等场景采用程序化对比——推荐量由代码计算，模型只负责把结论组织成自然语言。食物营养数据同时标注来源（《中国食物成分表（第六版）》）。

### RAG 语义检索

启动时将全部食物数据转为向量存入本地 ChromaDB。用户提问时，将问题转为向量，检索最相关的若干条食物注入对话上下文，使推荐有据可依。向量检索失败时回退到中文关键词匹配，保证能力始终可用。

### 长期记忆

每六轮对话触发一次提取，从对话中抽取用户的饮食相关事实（口味偏好、忌口等）存入长期记忆表，后续对话注入上下文，实现跨会话的个性化。

## 2. 食物库与营养数据

食物库共 769 条数据（公开 767 条），来源包括种子数据与两个中文食谱网站的爬虫导入。营养数据基于 213 种食材的营养参考（《中国食物成分表（第六版）》）按食材加权估算，并根据烹饪方式修正热量（炒、炸、烤、蒸、煮、炖各有不同系数）。营养数值由程序计算，不是模型生成。

## 3. 今天吃什么与决策辅助

支持关键词搜索与分类筛选，浏览食物卡片，并可将进食记录到饮食记录。决策辅助区提供四类能力：按辣度、菜系、热量、烹饪方式筛选食物；上传食材照片识别食材并生成菜谱建议；基于定位查询所在城市的美食并展示真实搜索结果；随机转盘在候选食物中随机决策。

附近美食通过浏览器定位（GPS 与地图接口）获取城市，再联网搜索该城市的特色美食，返回真实结果列表。

## 4. 我的厨房（DIY）

模拟厨房操作：双开门冰箱中选择食材、调料台中选择调料，食材以动画形式进入备菜盘。获取烹饪建议时，先匹配数据库中已有的食谱，匹配不到再由模型生成建议（菜名、烹饪方式、步骤、时间、热量）。随后选择烹饪方式并播放动画，保存为菜谱，可选发布到美食广场。保存后自动生成菜品配图，前端按优先级回退展示。

## 5. 美食广场与社区

用户分享的菜谱经管理员审核后公开展示。广场支持按热度、时间排序，热度按点赞与收藏加权计算。支持收藏与取消收藏。详情页包含食材、调料、做法、营养数据与评论区。评论支持楼中楼回复，作者或管理员可删除；评论数量达到阈值时自动生成 AI 评论总结。

## 6. 饮食记录与营养评估

记录每餐进食的食物与分量，自动计算热量并按烹饪方式修正。根据记录增量更新用户的辣度偏好与偏好菜系。提供近 7 天或 30 天的营养摄入图表，以及对照《中国居民膳食指南（2022）》的营养评估——推荐量按性别取值，实际摄入与推荐量对比得出正常、偏高或偏低的结论。

## 7. 记账

支持手动录入饮食消费，分类聚焦餐饮、外卖、零食、饮品、食材采购。上传账单截图可由模型识别金额、分类与描述，填入表单供确认后保存。统计图表展示分类占比与每日消费趋势。

## 8. 账号与安全

邮箱注册需验证码（发送接口限制频率防止滥用），登录签发 JWT。支持忘记密码、修改密码、头像上传与个人档案（年龄、性别、身高、体重）。图片地址经过安全校验防止服务端请求伪造，AI 客户端设置显式超时，登录与验证码接口有频率限制。

## 9. 管理后台

管理员登录后可查看平台统计、审核待发布的食谱、管理用户（封禁、解封、升降级、删除）。删除用户时先记录审计信息再清理关联数据，后台可查询已删除用户的审计记录。

## 10. 部署

支持容器化一键部署（MySQL、后端、前端三个容器），前端可安装为 PWA 应用并支持离线访问。

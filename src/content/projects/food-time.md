## 项目简介

省赛参赛项目，一个餐饮管理 Web 应用。

## 主要功能

- **菜品识别**：基于 Qwen VL 视觉模型识别菜品
- **智能推荐**：集成 DeepSeek 大模型做推荐
- **菜品管理**：Vue 3 + FastAPI + MySQL 前后端

## 技术栈

Vue 3 / FastAPI / MySQL / DeepSeek / Qwen VL

# 引言

zhan-Blog 是博主 zhan（一盏）的个人技术博客（也就是现在这个博客），用于**记录项目经历**、**分享开发教程**。博客基于开源主题改造，使用 Astro 静态生成，托管在 GitHub Pages 上，代码推送到仓库后自动构建上线。

这个博客本身也是一个完整的项目：除了文章展示，还带全文搜索、联系留言表单、内容管理后台、亮暗双模式与自定义主题色。下文按技术栈、页面结构、功能亮点三部分介绍。

# 项目简介

一句话：一个基于 Astro 的静态个人技术博客，包含文章与项目展示、全文搜索、联系留言表单、内容管理后台，支持亮暗双模式与自定义主题色，托管于 GitHub Pages。

## 技术栈与架构

- **框架**：Astro（静态生成）+ TypeScript；一次构建同时产出站点与搜索索引
- **样式**：Tailwind CSS + 自定义样式变量，配色、圆角、页面宽度等统一管理，支持主题化
- **交互组件**：Svelte 实现搜索框、归档面板、主题色滑块、亮暗切换等交互
- **搜索**：构建时生成全站离线搜索索引，访客端直接本地检索，不依赖外部搜索服务
- **文章展示增强**：代码块带行号与复制按钮、支持数学公式、图片点击放大、提示框组件、仓库信息卡片
- **页面切换**：无刷新过渡，带缓存与预加载
- **图标与字体**：多套图标库，三套本地字体
- **托管与部署**：GitHub Pages；代码推送到 main 分支后由自动化流水线构建发布
- **外部服务**：留言表单（直发博主邮箱）、访问统计（2026-08-12 接入）、评论（预留、未启用）、后台对接 GitHub 仓库
- **工程化**：pnpm 包管理、代码检查与格式化、类型检查、新文章模板生成脚本

# 页面结构

| 页面 | 说明 |
| :--- | :--- |
| 首页 | 欢迎语 + 精选项目 + 最新文章 |
| 归档 | 文章按年份分组的时间线列表 |

# 功能与技术亮点

## 1. 亮暗双模式与自定义主题色

亮暗切换支持浅色、深色、跟随系统三种模式，选择会记住，刷新页面不丢失。主题色通过滑块在 0–360 之间自由调整（默认蓝青色），同样持久保存，可一键重置回默认；全站配色由统一变量驱动，换色即时生效。

## 2. 全文搜索

构建时对全部文章建立离线索引，访客在搜索框输入关键词即可检索文章内容，结果展示标题与命中摘要片段，无需外部服务。

## 3. 文章阅读体验

- 代码块深色主题，带行号、复制按钮，长代码可折叠
- 支持数学公式渲染
- 正文图片点击可放大浏览、左右切换
- 提示框组件（提示 / 注意 / 重要 / 警告等类型），GitHub 风格
- 宽屏右侧固定目录导航，标题带锚点链接
- 文章头部显示字数与预计阅读时间
- 底部展示 CC BY-NC-SA 4.0 许可声明与上一篇/下一篇导航
- 文章按标题序号排序（如 01、02），上下篇自动关联

## 4. 归档、分类与标签

归档页按年份分组展示全部文章，左侧年份与日期、右侧标题与标签，支持按标签、分类筛选。侧边栏固定展示分类列表与标签入口，点击即可筛选对应文章。

## 5. 联系留言

联系页提供邮箱（一键写信、一键复制）与 GitHub 链接；留言表单提交后直接发送到博主邮箱，内置防垃圾机制，发送成功或失败都有明确提示。

## 6. 内容管理后台

不需要自建服务器，直接在浏览器里完成发文与管理：

- **授权**：填入 GitHub 访问令牌即可连接，令牌只保存在当前浏览器，不写进代码仓库，可随时断开
- **文章管理**：列出仓库中的全部文章，可查看、编辑、删除（删除需确认）
- **写文章**：可视化编辑器，实时预览 Markdown，支持语法快捷插入；本地图片一键上传到仓库并自动插入正文；提供图片库浏览已传图片、点击插入
- **发布**：填写标题、文件名、日期、分类、标签、摘要后一键发布，提交后约两分钟线上生效
- **编辑模式**：可加载已有文章继续编辑
- **统计**：后台内嵌访问统计面板，直接查看站点数据

## 7. 项目展示

项目以卡片呈现：标题、状态徽章、描述、技术标签、在线访问与仓库链接，整卡可点击进入详情页查看完整介绍。首页的"精选项目"区展示部分重点项目的卡片。

## 8. 订阅与统计

- RSS 订阅源，输出文章全文
- 站点地图自动生成
- 搜索引擎爬取规则配置
- 文章页附带结构化信息，方便搜索结果展示
- 全站接入访问统计，后台可看共享仪表盘

## 9. 自动部署

代码推送到 main 分支（或手动触发）后自动执行：安装依赖 → 构建站点与搜索索引 → 上传产物 → 发布上线。同一时间只允许一个部署任务，新推送会自动取代进行中的旧任务。

## 10. 预留能力

- **评论**：文章页已预留评论渲染入口，当前配置未开启；部署评论后端后修改配置即可使用
- **多语言**：内置多语言文案框架，当前站点语言为简体中文
